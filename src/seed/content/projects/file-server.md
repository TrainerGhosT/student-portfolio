### Descripción

Aplicación para transferir archivos entre un cliente y un servidor. Construida en Python, usa la API de sockets para comunicar ambas máquinas y permite enviar, recibir y eliminar archivos.

### Funcionalidades principales

- **Transferencia de archivos:** envío y descarga entre cliente y servidor.
- **Gestión de archivos:** eliminación de archivos en el servidor.
