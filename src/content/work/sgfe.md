### Sistema de Gestión de Ferias de Emprendedores

Es un sistema web construído para la Gestión y Planificación de
Ferias de manera eficiente, brindar claridad a los emprendedores,
y facilitar el análisis de la información para una mejor toma de
decisiones.

#### Features Principales

- Gestión de Ferias: Permite a los emprendedores gestionar sus
  ferias, incluyendo la creación, edición y eliminación de
  ferias.

- Seguridad y Autenticación: Proporciona proteccion mediante el uso de JWT para garantizar  la autenticación de los usuarios.

- Análisis de Información: Proporciona una interfaz para el análisis de información de las ferias, incluyendo la visualización de gráficos y tablas, y la exportación de datos en diferentes formatos.
