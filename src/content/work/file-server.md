### Proyecto File Server

 Es una aplicación diseñada para facilitar la transferencia de archivos entre un cliente y un servidor a través de la línea de comandos. Construida en Python, utiliza la API de sockets para establecer la comunicación entre las dos máquinas, permitiendo enviar, recibir y eliminar archivos de manera eficiente.


#### Features Principales

- Transferencia de Archivos: Permite al cliente enviar y recibir archivos desde el servidor de manera eficiente.

- Gestión de Archivos: Incluye la funcionalidad para eliminar archivos en el servidor, proporcionando control total sobre los datos almacenados.
