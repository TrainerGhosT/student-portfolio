### Proyecto Pagos Móviles

Pagos Móviles es un sistema de pagos digitales diseñado para
facilitar transacciones financieras fluidas entre usuarios de un
mismo banco o de distintos. Implementado a partir de una
arquitectura distribuida con múltiples componentes y tecnologías.

#### Componentes Principales 

- Servicio Externo: Maneja las solicitudes de pago entrantes y se comunica con el orquestador para procesar las transacciones. 
- Servicio Orquestador: Actúa como puente central, gestionando la comunicación entre el receptor externo, los servicios bancarios y los servicios web adicionales.
- Servicio Bancario: Procesa e interactúa con la base de datos para la verificación y actualización de la cuenta bancaria.
